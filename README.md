Descripción 
El programa esta desarrollado en Python como parte de la tarea de Fundamentos de la programación semana 14.
El programa permite ingresar 3 calificaciones y obtener el promedio.

El programa solicita 3 calificaciones:
1. Nota del parcial 1
2. Nota del parcial 2
3. Nota del parcial 3
Después de enviar las 3 notas la función realiza la suma de las 3 y divide el resultado para 3
Finalmente muestra el resultado.
